# 🚀 DashBoard01 - Istruzioni per l'avvio

## Prerequisiti
- .NET 10 SDK installato sul sistema

## Avvio del progetto
1. Assicurati di essere nella directory root del progetto
2. Esegui il comando:
   ```bash
   dotnet run
   ```

Il progetto sarà disponibile all'indirizzo: http://localhost:5000 (o porta simile)
